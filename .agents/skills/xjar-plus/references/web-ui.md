# 本机 Web UI 使用指南

本页说明 XJar Plus 2.0.0 网页界面当前实际提供的操作。UI 只提交两类任务：生成独立加密 JAR，或打包 Go 授权启动器。CLI 的检查、验证、解密、发行凭据初始化与许可证续期命令见 [commands.md](commands.md)。

## 启动、访问与退出

工具本身需要 Java 21。只在需要网页操作时显式运行 `ui`；不带 `ui` 不会启动网页服务：

```text
java -jar xjar-plus-2.0.0.jar ui
```

`--port` 接受 `0..65535`，默认是 `0`，由系统分配空闲端口；若希望使用固定端口，可指定端口并抑制自动打开浏览器：

```text
java -jar xjar-plus-2.0.0.jar ui --port 19876 --no-browser
```

服务只绑定 IPv4 回环地址 `127.0.0.1`。控制台打印实际访问地址，例如 `http://127.0.0.1:19876/`；请使用打印出的完整地址，不要改成机器名、远程 IP 或通过反向代理转发。固定端口被占用时，改用另一个端口或回到默认的 `--port 0`。如果图形桌面不可用或浏览器未能自动打开，复制控制台地址到本机浏览器即可；`--no-browser` 只关闭自动打开浏览器，不关闭服务。

控制台不打印会话令牌，也不需要手工复制令牌。打开本机页面时，服务会为当前进程生成会话值并放入页面会话；页面脚本自动在同源 API 请求中使用它。不要将页面或会话信息转交给远程客户端。服务要求 Host、Origin 和会话校验通过，不提供远程访问或跨域 API。

结束时在运行 UI 的终端按 `Ctrl+C`。这会关闭 HTTP 服务、当前系统选择器辅助进程，并请求活动任务协作式取消；服务会进行有界清理，但不能把关闭窗口当作任务成功的证据。若在任务完成前退出或中断，重新操作前先检查输出位置。UI 没有单独的“停止服务”网页按钮。

## 选择模式与填写字段

页面默认选中“独立加密 JAR”。切换模式不会清空已经填写的字段；任务运行或文件选择期间，模式和表单会暂时禁用。

### 两种模式共用

| 字段 | 必填/默认 | 用途与注意事项 |
| --- | --- | --- |
| 原始 JAR | 必填 | 输入待处理的可执行 JAR 路径。输入框接受手工路径；选择器只回填，不自动开始任务。输入 JAR 需要有可用的 `Main-Class`。 |
| 输出路径 | 必填 | 独立模式填新的加密 JAR 文件路径；Go 模式填发行父目录。父目录可以存在，但其中同应用的最终发行子目录不得存在。不要与输入使用同一文件。 |
| 密码 | 必填 | 两种模式都用此密码保护应用归档。任务提交后页面密码框会清空；重试或创建新任务时重新输入。丢失密码不能恢复归档。 |
| 同时加密嵌套依赖 | 可选；默认关闭 | 高级归档设置中的复选框。关闭时默认只处理应用自身的类和资源；勾选后才将可处理的嵌套依赖归档纳入处理。修改依赖归档会改变其字节内容。 |
| 加密路径规则 | 可选；默认空 | 高级归档设置中的包含规则；每个非空行是一条 glob 规则。 |
| 排除路径规则 | 可选；默认空 | 高级归档设置中的排除规则；排除匹配优先于包含匹配。 |

### 独立加密 JAR

选择“独立加密 JAR”后，填写上表的原始 JAR、输出文件路径和密码即可。它不要求 Go、`.issuer`、许可证或内嵌 JDK，也不执行授权到期限制。

输出选择器是“保存文件”类型。没有默认输出文件名或密码；请显式选择一个新路径。高级归档设置默认折叠，打开后可调整嵌套依赖和路径规则。

### Go 授权启动器

选择“Go 授权启动器”后，还必须填写以下三项：

| 字段 | 必填/默认 | 用途与注意事项 |
| --- | --- | --- |
| 稳定 `appId` | 必填；无默认值 | 应用的授权绑定标识。同一应用后续构建、首次许可证配置和续期必须使用完全相同的值。 |
| 发行方凭据文件 | 必填；无默认值 | 选择发布者持有的 `.issuer` 文件。它是签发秘密，不要交付给客户或放入导出配置。 |
| 目标平台 | 必填；默认未选择 | 必须明确选一个：`windows-amd64`、`windows-arm64`、`linux-amd64`、`linux-arm64`、`darwin-amd64`（macOS Intel）或 `darwin-arm64`（Apple Silicon）。 |

启动器高级设置默认折叠，包含：

| 高级字段 | 可选时的实际默认与行为 |
| --- | --- |
| 内嵌目标 JDK ZIP | 留空时使用目标机器提供的 Java；填写时 JDK 的系统和架构必须匹配所选目标平台。 |
| Go 编译器路径 | 留空时从构建机的 `PATH` 查找 Go；这是构建时工具，不要求目标机器安装 Go。 |
| 许可证生效时间 | 日期时间输入框默认为空；留空时由打包请求采用执行时的默认生效时刻。填写值按浏览器本地时区解释后转换为 UTC 时间点。 |
| 许可证到期时间 | 默认为空，表示永久有效。填写时必须晚于生效时间；到期边界不包含在有效期内。 |
| JVM 参数、应用参数 | 均默认为空。每个非空行作为一个独立参数传递，不会做 shell 分词、引号解析或变量展开；参数也可能含秘密，谨慎填写。 |

输出选择器是“选择目录”类型。输出目录中生成的启动器与 `key.x` 由打包结果给出的实际路径决定，不要根据 `appId` 自行拼接路径。打包成功不等于已经在目标系统验证过；启动、状态检查和续期步骤见下文及 [commands.md](commands.md)。

## 路径规则（include/exclude）

每行一条规则，规则按 Java 默认文件系统的 `glob` 匹配器解释，不是正则表达式。空行和纯空白行会忽略；其它行按原文本传递，因此不要在规则首尾误留空格。每个列表最多 128 条。

- 没有包含规则时，不额外通过 include 限定候选路径。
- 有包含规则时，候选归档路径匹配任意一条 include 即通过包含检查。
- 任何一条 exclude 命中都会排除该路径，因此 exclude 始终优先。
- 规则筛选的是归档处理范围；它不会强制开启嵌套依赖处理。要处理嵌套依赖仍需勾选“同时加密嵌套依赖”。

可参考页面占位示例：`com/example/**`、`config/*.yml`、`static/**`、`META-INF/NOTICE`。使用 `/` 书写归档路径；`*` 匹配单层路径部分，`**` 可表示多层路径。嵌套 JAR 条目按其容器路径与条目路径组合后匹配，复杂规则应在独立副本上构建并验证。

包名不是直接写 `com.example`。先用 `jar tf app.jar` 看真实路径：普通 JAR 常用 `com/example/**`；Spring Boot / 本仓库验证的 Solon 标准嵌套包使用 `BOOT-INF/classes/com/example/**`。例如在“加密路径规则”框逐行填写以下内容，保护两个业务包：

```text
BOOT-INF/classes/com/example/order/**
BOOT-INF/classes/com/example/payment/**
```

在“排除路径规则”框填 `BOOT-INF/classes/com/example/order/dto/**`，就会把 DTO 保留明文；不匹配的文件不会删除。这里填写的是规则文本，**不加命令行引号，不写 `--include`**。需要处理 `business.jar` 内的包时，勾选依赖加密并另填 `BOOT-INF/lib/business.jar!/com/example/secret/**`。更多资源、类、Multi-Release 和零级目录匹配示例见[完整筛选教程](commands.md#selection)。

## 选择文件、保存位置或目录

点击字段旁的选择按钮才会请求系统文件选择器。原始 JAR、`.issuer` 和 JDK ZIP 使用文件选择；独立模式的输出使用保存文件选择；启动器输出使用目录选择。Go 编译器路径没有系统选择按钮，需要手工填写。

选择成功只把路径写回字段，仍需你手动点击“开始加密”或“打包启动器”。选择期间当前按钮会改为“取消选择”，其它表单控件暂时禁用；点击它会请求关闭当前选择流程。取消系统对话框或请求取消时，原路径保持不变，不会自动提交任务。一次只允许一个系统选择器，选择流程最长等待约 300 秒。

- Windows 使用系统文件对话框辅助程序，优先尝试 PowerShell 7；启动或兼容失败时回退 Windows PowerShell 5.1。
- macOS 使用系统脚本文件面板。
- Linux 使用已安装的 `zenity` 或 `kdialog`；若两者都不可用则提示手工填写。

若选择按钮报错、系统对话框不可用或等待超时，可直接在路径输入框粘贴路径。路径字段不是命令行，粘贴时不要额外包一层引号；中文、空格路径可以直接填写。系统选择器的跨平台外观、焦点与高 DPI 行为尚未全部完成人工验收，手工路径是可用的备用方式。

## 进度、取消、重试与刷新恢复

提交后进度面板展示当前阶段、核心回报的百分比和状态消息。任务由后台队列执行，不需要保持浏览器页面一直可见。

- **取消任务**：活动任务显示此按钮。点击后是协作式取消请求，核心会在安全检查点停止；按钮反馈不是任务已经终止的证明。等待状态变为“已取消”或其它明确终态。
- **失败或取消后重试**：重试基于当前表单重新创建任务，不复用旧请求或旧密码。先检查并按需修改输出路径，再重新输入密码。已存在的输出不会因为重试而自动覆盖。
- **刷新或短暂断线**：提交前页面只把随机任务 ID 写入当前标签页的 `sessionStorage`，不保存密码、请求体或整个表单。刷新后只查询原任务状态，不自动重新执行加密或打包；若任务仍活动，可继续查看或请求取消。任务运行中，表单不会从后台恢复。
- **记录找不到**：任务记录仅存在于当前 UI 服务，最多保留 128 条；终态记录保留策略为 30 分钟且可能因容量提前回收。服务重启、记录过期或被回收后，页面无法确认原任务结果。先检查输出位置，再决定是否显式创建新任务，不要把“记录不存在”当作失败后可直接重放。
- **浏览器会话存储不可用**：页面会在提交前提示，且不会声称刷新后能恢复；改用支持会话存储的浏览器或 CLI。

提交确定被服务拒绝时，页面会显示未受理原因，可修改当前表单后再试。遇到网络中断或结果无法确认时，页面先查询任务 ID；不要另开一次任务代替状态确认。

## 配置导入与导出

“导出配置”会下载 `xjar-plus-config.json`，包含当前模式和非敏感设置：

```text
mode, input, output, appId, target, jdkZip, goExecutable,
encryptDependencies, includes, excludes, notBefore, notAfter
```

导出保留本机输入/输出路径、JDK/Go 路径和授权配置值，分享文件前检查并按需修改这些本机信息。导出明确不包含密码、发行方 `.issuer` 路径、JVM 参数和应用参数；这样也避免参数中可能存在的秘密被意外带出。

“导入配置”只读取不超过 256 KiB 的 JSON 对象，并应用页面认识的字段。include/exclude、JVM 参数和应用参数可以用数组或换行文本导入；导出不会保存 JVM/应用参数。导入不会填写或覆盖密码和发行方凭据路径，即使 JSON 手工包含这些字段也不应用。导入后检查模式、路径和高级设置，重新选择 `.issuer` 并单独输入密码。配置文件无效或超过大小限制时，页面显示错误，不启动任务。

## 完成后验证与 UI 边界

UI 只负责 `encrypt` 和 `package`，本身不提供 `inspect`、`verify`、`decrypt`、`doctor`、`license init`、`license issue` 或许可证状态页。完成构建后，独立加密 JAR 应用 CLI `verify` 后再在目标 Java 环境实际启动；Go 启动器应连同对应 `key.x` 在目标平台实际运行并检查健康/授权状态。CLI 验证、许可证首次初始化和续期命令见 [commands.md](commands.md)。许可证续期使用原有发行凭据及相同 `appId`，把新签发的 `key.x` 部署到启动器旁并重启；不要在 UI 中寻找续期按钮。

UI 与 CLI 使用同一归档核心。可执行普通 JAR 需要有效 `Main-Class`；Spring Boot、Solon 等固定验证版本见 [Release 附带的兼容矩阵](https://github.com/kongweiguang/xjar-plus/releases/tag/v2.0.0)。WAR、Native Image、JPMS 启动及任意自定义 Launcher 不在支持范围。成功显示“已完成”只表示核心构建任务完成，不替代目标 JDK、系统和业务中的启动验证。
