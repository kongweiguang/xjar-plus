参数助手

xjar-plus 的启动加载链路不需要打开 JDK 内部包；业务依赖报模块访问问题时，再按具体异常最小化处理。

-XX:+DisableAttachMechanism
-XX:+DisableAttachMechanism

关闭 Attach 机制，减少运行中被 jcmd、jstack、调试器或外部 Agent 动态附加的入口。

-Dfile.encoding=UTF-8

固定文件编码，避免不同机器默认编码导致配置、日志或路径文本乱码。

-Duser.timezone=Asia/Shanghai

固定 JVM 默认时区，避免服务器时区不同导致日志、授权时间或业务时间偏移。

-Xms512m -Xmx1024m

设置初始和最大堆内存。一般建议 Xms 不大于 Xmx，按应用体量和机器内存调整。

-XX:+UseG1GC

启用 G1 垃圾收集器，适合大多数服务端应用；新版 JDK 通常默认已经是 G1。

-XX:MaxGCPauseMillis=200

给 G1 一个期望停顿目标，不是硬保证；接口服务可按延迟目标调整。

-XX:+HeapDumpOnOutOfMemoryError

发生 OOM 时导出堆转储，便于定位内存泄漏或异常对象占用。

-XX:HeapDumpPath=./logs/heapdump.hprof

指定堆转储文件位置。生产环境建议放到空间充足、可收集的目录。

-XX:+ExitOnOutOfMemoryError

OOM 后直接退出进程，交给守护进程或容器重启，避免服务处于不可靠状态。

-Xlog:gc*:file=./logs/gc.log:time,uptime,level,tags:filecount=5,filesize=20m

JDK 9+ GC 日志写法，保留滚动文件，方便观察停顿、回收频率和内存变化。

-Dspring.profiles.active=prod

Spring Boot 常用环境参数，用于选择 prod、test、dev 等配置集。

-Dserver.port=8080

Spring Boot 常用端口参数，需要固定端口或避开端口冲突时使用。

-Djava.security.egd=file:/dev/./urandom

Linux 下减少旧环境随机数阻塞。新版 JDK 和大多数 Windows 场景通常不需要。
