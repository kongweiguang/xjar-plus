# Go 启动器

本模块由 Java 打包器复制到私有暂存目录，写入应用、配置和可选 JDK 后编译。直接构建仓库占位载荷不会得到可运行的客户分发件，而会明确报告配置缺失。

- `cmd/launcher/`：入口与内嵌文件；`internal/`：授权、供钥、进程监督、状态接口和 JDK 准备。
- `key.x` 位于生成的启动器旁；换证后需重启。发行凭据 `.issuer` 不进入客户包。
- 配置版本为 2，包含稳定 `appId`、构建 `artifactId`、独立数据/授权密钥、最低 Java 版本和 argv 数组；具体格式见 [协议说明](../docs/format-v2.md)。
- 内嵌 JDK 会校验路径、系统/架构、版本及可执行文件后解压到私有目录；不内嵌时先查 `JAVA_HOME`，再查 `PATH`。
- 业务标准输入/输出/错误流直接继承，参数按数组传递，不拼接 shell。

状态服务仅监听 IPv4 回环，默认 `127.0.0.1:19527`。`XJAR_PLUS_STATUS_PORT=0` 使用随机端口，或设为 `1..65535`；日志显示实际监听地址。`/xjp/healthz` 只表示状态服务可用，授权是否有效与业务是否运行需检查 `/xjp/license/status`。

开发检查（在此目录执行）：

```text
go test ./...
go vet ./...
```

实际打包、到期停机边界和续期步骤见 [使用指南](../docs/usage.md)；交叉编译不等于目标平台已实测。
